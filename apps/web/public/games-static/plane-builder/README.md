# Sky Builder - Flight Lab

A simple offline HTML/CSS/JS prototype inspired by the car-building game, adapted for aircraft learning.

## Files
- index.html
- styles.css
- app.js
- data/parts.json
- data/missions.json
- data/anatomy.json

## Run
Open `index.html` in a browser, or serve the folder locally if your browser blocks `fetch()` from local files.
A simple option is VS Code Live Server.

## What is included
- Mission-based plane building
- Install/remove parts
- Child-friendly diagnostics
- Flight test button
- Anatomy learning cards
