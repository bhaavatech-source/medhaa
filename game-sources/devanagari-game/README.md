# Akṣarābhyāsaḥ - Devanāgarī

Editable React/Vite source for Medhaa's `devanagari-game`. The active entry is
`src/main.tsx`; supplied root-level component copies are not used by that entry.

From the Medhaa repository root, run `npm run build:devanagari` to type-check,
build and publish the production files to the existing static game URL.

See [DEPLOY.md](./DEPLOY.md) for dependency setup, platform contracts, validation,
audio publishing and release steps.
